# 晚安邮局 · 故事声音产品设计

**家长应该能在十几秒的试听里判断“我愿意让这个声音讲完一篇故事吗”。** 孩子听到的应是家长选定的那版录音。下次打开同一本绘本，小狐狸依旧用熟悉的声音讲话。

上一版三篇书使用基础婷婷音色。当前首页的三篇样音已换用本机增强普通话音色，分别编排对白、转折与结尾的停顿、语速和音高。自创故事仍使用设备端可用的普通话语音，两类声音来源在播放器中标示。正式选声还需家长盲听；流程见下文，服务商方案见[语音合成技术设计](voice-architecture.md)。

## 一次配音应该怎么做

| 时刻 | 家长看到什么 | 产品行为 |
|---|---|---|
| 确定稿件 | 「听听这一段」和一段含旁白、对话的原文 | 优先选本篇有代表性的 10–20 秒。家长也可以圈选读音拿不准的一句话。 |
| 选择声音 | 绘本风声音卡片，默认「温柔晚安」，另一个候选「明亮故事」。每张标明使用的真实音色。 | 初次试听可播项目自有的公共样音；合成本篇私有试音前，说明发送的文字、服务商和可能产生的费用。切换候选沿用同一段文字。 |
| 确认全篇 | 「用这个声音讲完整篇」；同屏显示字数、服务商、预估空间和已知价格。 | 沿用刚刚试听的音色、模型与节奏。已通过听审的完全相同版本可直接取用。 |
| 听审和修改 | 能听开头、跳到任意段落或听结尾。「这里没读对」可把名字读音改好，再试听该段。 | 保留原稿；读法修正在朗读稿中记录。改一段可仅重做受影响的片段。允许中断并继续听审。 |
| 发布与重播 | 家长点「放进书架」，选可收听的孩子。 | 孩子播放已确认完整录音；未确认的新版本留在家长区。撤回后取消后续读取权限。换 Key 或服务商仍可重播已保存的作品。 |

朗读能力与写作能力独立配置。公开首页的样音标明实际来源；上架正式声音时，公开样音使用有相应用途授权的文本、音色和录音。儿童端只提供收听操作，不显示付费生成、服务商或密钥。

## 要听见的变化

用《月亮邮差》的两句原文做第一轮试听：

> 小青蛙探出头来说：“今晚的月亮在我家做客呢！”风轻轻一吹，水里的月亮碎成了好多小银片。

“探出头来说”应自然带入对白。青蛙略带惊喜，音量仍能让人放松。说完“呢”，给听众一点想象的时间；回到“风轻轻一吹”，应能感觉旁白接了回来。记录出现问题的词或秒数，例如“‘做客’之前停了一下，像在逐字念”。仅写“太机械”很难指导下一轮调整。

| 现象 | 优先检查 | 家长可选动作 |
|---|---|---|
| 人名、多音字读错 | 读音词典、上下文和数字读法。例如“银行门口排着一行人”中两个“行”。 | 指定读法并试听这一句。 |
| 对白像播报，感叹句过响 | 音色是否适合叙事、角色切换时的重音、音量突变。 | 换声音，在同一句上比较。 |
| 每句话等长，停顿像断线 | 旁白与对白边界、换段时是否重复加入停顿、模型断句。 | 从出问题的前一句开始试听。 |
| 开头悦耳，后段声音越来越尖或换了说话人 | 长篇分段后的音色和语速一致性。 | 对照前后两段，保留满意的版本。 |
| 小音量听不清，结尾突然被截掉 | 手机外放、齿音、吞字、尾音和录音编码。 | 试听末句；报告时保留录音版本和时间点。 |

「温柔晚安」采用单人旁白、柔和起音、自然段落留白。「明亮故事」可以让对白更有起伏。默认关闭背景音乐和突发音效；语速、发音修正放入声音详情。首轮用相同文本筛音色，再调节语速，每轮只改一个因素。

## 候选声音与盲听

建议第一轮比较现有录音、Azure 普通话神经音色与百炼 CosyVoice 普通话音色。Azure 可试 Xiaoxiao 的 gentle、Yunxi 的 narration-relaxed；CosyVoice 从所选模型支持的普通话系统音色中选一款，例如 cosyvoice-v3-flash 的 longanyang。这些是待评候选，具体地域、模型和声音能力在接入时复核。获取实样前，按家庭授权和服务商规则确认费用及用途。[Azure 音色与风格](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=text-to-speech) · [百炼音色与试听](https://help.aliyun.com/zh/model-studio/cosyvoice-voice-list)

1. 选三段各约 15–25 秒的文字，分别覆盖平静旁白、角色问答、专有名和多音字；另备一段约 3 分钟的连续故事，检查耐听度。每个候选使用同稿、同段边界，调到相近的感知音量，去掉品牌标签，随机交换 A/B 顺序。
2. 首轮邀请至少 8 位目标家长。手机外放低音量、耳机各听一次，记录自然度、清晰度、睡前舒适度（各 1–5 分）、是否更愿意听完整篇，以及最希望改的一处。评分与设备、样音版本、准确时间点关联。
3. 建议首轮准入线为三项中位数均至少 4 分；同基线成对比较，至少 6/8 位家长偏好候选或在更大样本中达到相同比例。任何经复核的漏句、重复、明显爆响、错读主角名字均须修复并复听。这些数字用于本产品决策，尚未取得实测分数。
4. 家长再次确认整篇长样本后，将优胜音色标记为家庭可选。偏好分散时保留两种声音，样本不足时继续收集。每次模型或音色换版都保留旧版用于复听。

**交付给评审者的记录**应包括候选 ID 与日期、原文、各版音频、三项评分、偏好票和问题时间点。听感改进以真实候选录音及盲听结果为依据。更换播放器或降低播放速度可以单独验收操作体验。
